fixed test first: the regression test failed on the old code (or killed a mutant that removes the fix) and passes now.

- **FIXED**: code changed, with its commit and test.
- **DOCUMENTED**: docs or NatSpec corrected.

  pending.
- **DEP-01** (non-EVM vault immutability unchecked): PENDING, owner decision on each part (B1-02, B2-01, B4-01, B3-02).
