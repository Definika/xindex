# Triage of the 2026-09-23 security audit

Findings: `audit/2026-09-23-security-audit.md`, a review of `855e41b`. The repository cites them as `CR-M01`,
`CR-L01` to `CR-L08` and `CR-I01` to `CR-I41`: the report's own ids with the review's prefix, because M01, L03, L06,
L08, I02, I03 and I09 to I12 are already v1 ids. A test is named after its id the way AGENTS.md gate 6 asks
(`test_CRM01_...`, `testFork_CRL08_...`, `test_XA30_CRI23_...` where it pins an earlier id as well).

Each finding was triaged the way `audit/triage.md` asks: a test that reproduces the defect, watched failing, then the
fix, watched passing. Twenty-one of the findings are test gaps, where the defect is that a safety check could be
changed without any test noticing; for those the evidence is the mutant the audit named, applied to `src/` or
`script/`, failing the new test, and `src/` and `script/` restored byte for byte afterwards. Every mutant listed below
was run that way.

Dispositions:

- **FIXED:** the code changed, a test that was missing was added, or both.
- **DOCUMENTED:** docs or comments changed, and nothing else needed to.
- **DISMISSED:** no change, with the reason. None.

Status: 50 findings triaged, **29 FIXED, 21 DOCUMENTED, 0 DISMISSED, 0 PENDING.**

Round 3 of the audit was cut short, and its findings, L-07, L-08, I-20, I-21 and part of I-36, went unverified in the
report. Each was checked against the code and the git history before it was fixed, and each held.

Four fixes change what the contracts do, not only how they are tested or described, and each changes an ABI-visible
behaviour or a documented decision:

- **Every token config must carry a reference supply (CR-M01, CR-L03, CR-L07).** `IndexRule.checkConfig` reverts
  `ZeroSupply` for a zero `referenceSupply`, and the rule reads no supply live. This is the report's second and
  stronger recommendation for M-01, adopted in place of listing wstETH alone with a reference figure, because it closes
  the class rather than the instance: nothing inside a transaction can move a supply the rule reads.
- **The capped methodology's top ceiling follows the lead (CR-L01).** 20% at a tie with the runner-up, rising
  linearly to 30% at twice its market cap. This changes a product decision (AGENTS.md, "Product decisions"); a basket
  led twice over or more, the Numbers model's and every capped subset of the launch list, is unchanged.
- **`MIN_SETTLEMENT_RATIO` is 0.875 (CR-L06),** up from 0.85, within the 0.87 to 0.88 the report measured as refusing
  no competitive fill.
- **An index refuses its own shares (CR-I01).** `IndexToken._update` reverts `InvalidRecipient` for a transfer or mint
  to the index itself.

The owner approved the first three on 2026-09-23, together with keeping wSOL on the launch list (CR-L05, CR-I39); the
AGENTS.md product decisions record all four.
